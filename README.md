# PO-GAN: Policy Optimized Generative Augmentation for Imbalanced Acne Severity Classification

Official code for the paper:

> **PO-GAN: Policy Optimized Generative Augmentation for Imbalanced Acne Severity Classification**
> Apiwit Puangsricharern and Suppawong Tuarob
> Faculty of Information and Communication Technology, Mahidol University
> Submitted to ACM Transactions on Computing for Healthcare (HEALTH), 2026

## Overview

PO-GAN is a framework that uses black-box optimizers (Genetic Algorithm and Bayesian Optimization) to discover per-class synthetic image allocation policies that maximize validation macro-F1 for acne severity classification. The classifier uses a Label Distribution Learning (LDL) architecture, and synthetic images are generated by StyleGAN2-ADA fine-tuned on clinical acne photographs.

## Data Preparation

### Real Datasets

This study uses two public acne severity datasets:

1. **ACNE04** (1,457 images, 4 severity classes)
   - Source: Wu et al. "Joint Acne Image Grading and Counting via Label Distribution Learning" (ICCV 2019)
   - Download from the original authors and place images in `data/acne04/`

2. **AcneSCU** (276 images, 4 severity classes)
   - Source: Shen et al. (Sichuan University)
   - Download from the original repository and place images in `data/acnescu/`

The stratified 5-fold cross-validation splits are provided in `data/splits/`. Each line has the format:
```
<filename> <severity_class> <lesion_count>
```

### Synthetic Images

Synthetic images are generated using StyleGAN2-ADA fine-tuned on each dataset. Pre-trained GAN weights are available at:
- **[Zenodo link TBD]** or **[Google Drive link TBD]**

Place `.pkl` files in `weights/` and use the generator to produce synthetic images:
```bash
cd generator
python generate.py --outdir=../data/acne04/fakes --seeds=0-999 \
    --network=../weights/acne04_stylegan2ada.pkl
```

## Usage

### 1. Vanilla Baseline (real data only)

```bash
cd classifier
python training/train_script_224.py \
    --data ../data/splits/acnescu \
    --out results/acnescu_vanilla \
    --images_base ../data/acnescu
```

### 2. Run Optimization (GA or BO)

```bash
python optimization/optimize_ldl.py --config configs/cfg_2026_acnescu_ga.yaml
```

### 3. SOTA Baselines (Focal Loss, Class-Balanced Loss, Zein Proxy)

```bash
python optimization/run_sota_baselines.py --config configs/acnescu_sota.yaml
```

### 4. Ablation (Real Oversampling + Class Weighting)

```bash
python optimization/run_baseline_ablation.py --config configs/acnescu_ablation.yaml
```

## Key Results

| Method | ID | ACNE04 Val F1 | ACNE04 Test F1 | AcneSCU Val F1 | AcneSCU Test F1 |
|--------|----|:---:|:---:|:---:|:---:|
| Real-only Baseline | -- | 0.8242 | **0.7847** | 0.4408 | 0.4033 |
| Focal Loss | -- | -- | 0.7816 | -- | 0.3950 |
| CB Re-weight | -- | -- | 0.7788 | -- | 0.5047 |
| Zein Proxy | -- | -- | 0.7388 | -- | 0.4553 |
| PO-GAN (GA) | g2_i4 / g2_i5 | 0.8223 | 0.7778 | 0.6041 | **0.5263** |
| PO-GAN (BO) | bo_72 / bo_22 | 0.8303 | 0.7768 | 0.6173 | 0.5241 |

All values are macro-F1 (f1_macro_sane: NaN→0, always /4 classes). Val F1 selects champions; Test F1 is reported once at the best validation epoch. Champions: ACNE04 uses g2_i4 (GA) and bo_72 (BO); AcneSCU uses g2_i5 (GA) and bo_22 (BO).

### Real Oversampling (RealOS) Ablation

To isolate whether the benefit comes from the *allocation policy* or from the *synthetic images themselves*, each champion allocation vector is re-run with the synthetic pool replaced by duplicated real training images at identical per-class counts. Only the source of the augmentation images changes.

| Method | ACNE04 Test F1 | AcneSCU Test F1 | AcneSCU folds improved |
|--------|:---:|:---:|:---:|
| Real-only Baseline | 0.7847 | 0.4033 | -- |
| RealOS (GA counts `[110,4,54,44]`) | 0.7728 | 0.5093 | 3 / 5 |
| RealOS (BO counts `[112,0,7,108]`) | 0.7868 | 0.4919 | 3 / 5 |
| **PO-GAN (GA)** | 0.7778 | **0.5263** | **5 / 5** |
| **PO-GAN (BO)** | 0.7768 | 0.5241 | **5 / 5** |

Key finding: on AcneSCU both methods lift the mean, but they diverge by fold. On the two *strong* folds (benchmark macro-F1 ≥ 0.50), PO-GAN gains +0.022 on average while RealOS **loses** −0.097 (fold 1: −0.167). On the three *weak* folds (benchmark < 0.40), both help substantially. PO-GAN improves all 5 folds; RealOS improves only 3 of 5. Duplicated real images help a data-starved classifier but can hurt when the baseline is already reasonable, whereas synthetic images add new variety without that cost. Reproduce with `run_baseline_ablation.py` (step 4 above).
